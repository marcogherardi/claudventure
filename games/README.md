# Game files

Put the Scott Adams games here, in ScottFree / TRS-80 `.dat` format (`adv01.dat`,
`adv02.dat`, ...). They are not included in this repository because they are still
copyrighted by Scott Adams.

The *Scott Adams Collection* in this format is available from the
[Interactive Fiction Archive](https://www.ifarchive.org/indexes/if-archive/scott-adams/).
